# Bulk Related Contact Cleaner

A Chrome Manifest V3 template for clearing a configured related-contact field and disabling an associated setting across records.

## Configure before use

Replace the example host in `manifest.json`. Review the default value in `popup.html`, then update the selectors, record-link pattern, application edit/save hooks, and verification rules in `background.js`. Test on a non-production site first.

## Install

Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select this folder.

Provided as a reusable template. Use only on sites and data you are authorized to automate.
