# Bulk Contact Replacer

A Chrome Manifest V3 template for finding one configured contact across records, replacing it with another, and exporting a result log.

## Configure before use

Replace the example host in `manifest.json`. In `background.js`, replace the placeholder contact values and review all selectors, routes, pagination functions, and save actions. Test on a non-production site first.

## Install

Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select this folder.

Provided as a reusable template. Use only on sites and data you are authorized to automate.
