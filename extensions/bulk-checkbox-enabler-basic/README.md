# Bulk Checkbox Enabler — Basic

A Chrome Manifest V3 template for paging through records and enabling configured checkboxes.

## Configure before use

Replace the example host in `manifest.json`, then review the selectors, record-link pattern, pagination behavior, and save action in `background.js`. Test on a non-production site first.

## Install

Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select this folder.

Provided as a reusable template. Use only on sites and data you are authorized to automate.
